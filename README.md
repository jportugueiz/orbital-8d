# ORBITAL 8D AI Studio

Aplicación web binaural de producción y Sound Healing creada por Jorge.

La aplicación se ejecuta directamente en el navegador. Para escuchar la espacialidad 8D se recomienda usar audífonos a volumen moderado.

## Uso

Abre `index.html` mediante GitHub Pages. Los archivos de audio incluidos forman parte del paquete de publicación de ORBITAL y conservan sus créditos y licencias en la propia aplicación.
